College Experience

Before College - Early Skills Foundation

Before entering college at CSTA (Colegio de Sta. Teresa de Avila), I already had basic experience in Python programming. I explored biometric-related projects such as facial recognition systems and hand motion detection, which sparked my interest in system development and artificial intelligence concepts early on.

1st Year - 1st Semester

During my first semester, I started learning Java as my first formal programming language. I also had a little experience in VB.NET, which helped me understand basic programming logic and system structure.

1st Year - 2nd Semester

I improved significantly in VB.NET through self-learning and practice. I gained deeper knowledge in MySQL database and Microsoft Access, which strengthened my ability to create database-driven applications.

2nd Year - 1st Semester

I focused more on integrating databases with VB.NET systems. I also learned system design, UI development, deployment process, and improving overall user interface and user experience in applications.

2nd Year - 2nd Semester

I started exploring HTML for web development, although it felt more complex compared to VB.NET drag-and-drop development. Despite that, I continued learning and focused more on AI integration in my projects. This is where I discovered tools like GPT4All and Ollama 3, which expanded my understanding of AI-based systems.

🚀 Keep Exploring...

My journey in IT is still ongoing. I am continuously learning new technologies, improving my programming skills, and exploring more advanced fields such as Artificial Intelligence, Web Development, and System Integration. More experiences, challenges, and projects will be added soon as I grow in this field.
